Discover the core query APIs on individual primitives. These minimal snippets mirror the full example and are safe to copy into small test programs. Start by constructing a few primitives, then combine the basic queries to validate geometry, measure distances, and test interactions.

```cpp [query_on_primitives.cpp]
// Intersections and closest points
auto tri0 = tf::make_polygon(std::array{
  tf::point<float,3>{0,0,0}, tf::point<float,3>{3,0,0}, tf::point<float,3>{1.5f,3,0}
});
auto tri1 = tf::make_polygon(std::array{
  tf::point<float,3>{1.5f,-1,-1}, tf::point<float,3>{1.5f,-1,2}, tf::point<float,3>{1.5f,2,0.5f}
});

bool hit = tf::intersects(tri0, tri1);
auto [d2, pt_on_0, pt_on_1] = tf::closest_metric_point_pair(tri0, tri1);
float d = tf::distance(tri0, tri1);
```

The same APIs work across all supported primitive pairs (segments, rays, planes, polygons), so you can mix-and-match without changing your workflow.

```cpp [query_on_primitives.cpp]
// Classification
auto plane = tf::make_plane(tri0);
tf::point<float,3> p_above{1.5f, 1.0f, 5.0f};
auto side = tf::classify(p_above, plane);          // tf::sidedness
auto inside = tf::classify(tf::point<float,3>{1.5f,1,0}, tri0); // tf::containment
```

Classification is useful for quick spatial tests (e.g., point-in-polygon or half-space checks) without constructing additional data structures.

```cpp [query_on_primitives.cpp]
// Ray casting and ray hit
auto ray = tf::make_ray(tf::point<float,3>{1.5f, 1.0f, 5.0f}, tf::vector<float,3>{0,0,-1});
if (auto r0 = tf::ray_cast(ray, tri0)) {
  auto [status, t] = r0;
}
if (auto r1 = tf::ray_hit(ray, tri0)) {
  auto [status, t, pt] = r1;
}
```
Use ray queries when you need parameter t (for picking) or the explicit hit point. The cast/hit pair provides a light-weight API for either use-case.
