Build and explore the example programs. Use this page to jump into the four focused guides in this section.

```bash [Terminal]
mkdir build
cd build
cmake ..
make examples -j8
```

## Sections

- [Primitive Queries](/examples/primitive-queries): fundamental geometric queries on low‑level primitives (intersections, closest points, distances, classification, ray casting).

- [Point Cloud Cleanup](/examples/point-cloud-cleanup): identify nearly‑coincident points within a tolerance using a spatial tree; ideal as a preprocessing step before topology and simplification.

- [Mesh Self‑Intersection](/examples/mesh-self-intersection): find all intersecting triangle pairs between a mesh and a transformed copy using trees, frames, and forms.

- [VTK Intersection Curves](/examples/vtk-intersection-curves): interactively move meshes and render intersection curves in real time with a thin VTK bridge.
