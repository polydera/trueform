---
title: Mesh Self‑Intersection Search
description: Find intersecting triangle pairs between a mesh and a transformed copy using trees, frames, and forms.
navigation:
  icon: i-lucide-search
---

Detect self-collisions by querying a mesh against a dynamically transformed version of itself. This approach avoids duplicating memory: the static geometry is indexed by a single tree, and transformations are applied on-the-fly via frames.

```cpp [find_intersecting_primitives.cpp]
// Create polygons view from raw data
std::vector<int> faces = {/* tri indices ... */};
std::vector<tf::point<float,3>> pts = {/* ... */};
auto polys = tf::make_polygons(tf::make_blocked_range<3>(faces), tf::make_points(pts));

// Build tree once over static geometry
tf::tree<int, float, 3> tree(polys, tf::config_tree(4, 4));
```

Trees accelerate broad-phase culling and are built once per static dataset. The same tree can back multiple dynamic queries.

```cpp [find_intersecting_primitives.cpp]
// Dynamic frame to transform the second form on-the-fly
auto R = tf::transformation<float,3>{/* 3x4 row-major */};
auto T = tf::make_transformation_from_translation(tf::vector<float,3>{1.5f,1.5f,0.5f});
auto frame = tf::make_frame(tf::transformed(R, T));

auto formA = tf::make_form(tree, polys);
auto formB = tf::make_form(frame, tree, polys);
```

Forms combine a tree, polygons, and an optional frame into a single queryable object.

```cpp [find_intersecting_primitives.cpp]
// High-level: collect all intersecting triangle id pairs
std::vector<std::pair<int,int>> pairs;
tf::gather_ids(formA, formB, tf::intersects_f, std::back_inserter(pairs));

// General search: flexible narrow-phase
tf::local_vector<std::pair<int,int>> pairs2;
tf::search(formA, formB, tf::intersects_f, [&](const auto& a, const auto& b){
  if (tf::intersects(a, b)) pairs2.push_back({a.id(), b.id()});
});
```
Choose the high-level API for convenience, or the general search to attach custom logic and outputs.
