Clean up noisy point clouds by grouping near-duplicates within a tolerance, powered by spatial search on a `tf::tree`. This is a common pre-step for watertight topology, welding vertices, or preparing data for meshing and simplification.

```cpp [find_coincident_points_with_tolerance.cpp]
// Build a points view, acceleration structure, and a form
std::vector<tf::point<float,3>> pts = {/* ... */};
auto points = tf::make_points(pts);
tf::tree<int, float, 3> tree(points, tf::config_tree(8, 8));
auto form = tf::make_form(tree, points);
```

Building a tree over your points provides the broad-phase needed to keep searches sublinear, even on millions of points.

```cpp [find_coincident_points_with_tolerance.cpp]
// High-level: collect coincident pairs with broad & narrow predicates
float tolerance = 1e-3f;
float tolerance2 = tolerance * tolerance;
std::vector<std::pair<int,int>> close_pairs;
tf::gather_self_ids(
  form,
  [tolerance](const auto& aabb0, const auto& aabb1){
    return tf::distance(aabb0, aabb1) < tolerance;
  },
  [tolerance2](const auto& p0, const auto& p1){
    return tf::distance2(p0, p1) < tolerance2;
  },
  std::back_inserter(close_pairs)
);
```

Prefer the high-level call when you just need ids; it handles parallelism and buffering for you.

```cpp [find_coincident_points_with_tolerance.cpp]
// General search: broad & narrow phases with thread-local collection
tf::local_vector<std::pair<int,int>> pairs;
tf::search_self(
  form,
  [tolerance](const auto& aabb0, const auto& aabb1){
    return tf::distance(aabb0, aabb1) < tolerance;
  },
  [&](const auto& p0, const auto& p1){
    if (tf::distance2(p0, p1) < tolerance2) pairs.push_back({p0.id(), p1.id()});
  }
);
```
Use the general form to implement custom predicates, accumulate extra attributes, or integrate with existing data structures.
