Interactively move meshes in a VTK scene and visualize intersection curves computed by trueform. A thin bridge converts trueform ranges into `vtkPolyData` for rendering.

```cpp [forms_intersections.cpp]
// Build forms with frames/trees and semantic tags
auto form0 = tf::make_form(frame0, tree0,
  tf::make_polygons(get_triangle_faces(poly0), get_points(poly0).as<double>()))
  | tf::tag(face_membership0)
  | tf::tag(manifold_edge_link0);

auto form1 = tf::make_form(frame1, tree1,
  tf::make_polygons(get_triangle_faces(poly1), get_points(poly1).as<double>()))
  | tf::tag(face_membership1)
  | tf::tag(manifold_edge_link1);
```

Tags keep per-face membership and manifold connectivity available during transformations, ensuring consistent intersection labeling.

```cpp [forms_intersections.cpp]
// Compute intersection curves
auto curves = tf::make_intersection_curves(form0, form1);
// Bridge to VTK (sketch): convert curves.curves() to vtkPolyData
auto poly = curves_to_polydata(curves.curves());
```
Once converted, use a standard VTK pipeline (e.g., `vtkTubeFilter`) to style the curves for display.
