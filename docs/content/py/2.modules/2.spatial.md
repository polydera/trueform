The Spatial module extends core queries to forms with spatial acceleration structures.

## Forms

In trueform, `Mesh`, `EdgeMesh`, and `PointCloud` represent **forms** - geometric objects equipped with spatial acceleration structures. These structures enable efficient queries on large datasets by leveraging the underlying `tf::tree` spatial hierarchy.

| **Form**       | **Description**                                    | **Elements**           | **Dimensions** |
|----------------|----------------------------------------------------|------------------------|----------------|
| `PointCloud`   | Collection of points                               | Points                 | 2D, 3D         |
| `EdgeMesh`     | Collection of line segments (edges)                | Edges (2 verts)        | 2D, 3D         |
| `Mesh`         | Polygonal mesh (triangular or quad faces)         | Faces (3 or 4 verts)   | 2D, 3D         |

::tip{icon="i-lucide-zap"}
**Spatial Tree Building**: The spatial tree is built automatically on first use of any spatial query. For performance-critical applications, you can prebuild the tree using `form.build_tree()` to avoid the cost during the first query.
::

### PointCloud

Represents a collection of points:

```python
import trueform as tf
import numpy as np

# Create point cloud
points = np.random.rand(100, 3).astype(np.float32)
cloud = tf.PointCloud(points)

# Access properties
print(f"Point cloud has {len(cloud)} points in {cloud.dims}D")

# Prebuild spatial tree for performance (optional)
cloud.build_tree()  # Tree is built automatically on first query if not called
```

### EdgeMesh

Represents a mesh of line segments:

```python
# Create edge mesh (polyline or collection of segments)
edges = np.array([[0, 1], [1, 2], [2, 3]], dtype=np.int32)
points = np.array([[0, 0], [1, 0], [1, 1], [0, 1]], dtype=np.float32)
edge_mesh = tf.EdgeMesh(edges, points)
```

### Mesh

Represents a polygonal mesh (triangles, quads, etc.):

```python
# Triangle mesh (each face has 3 vertices)
faces = np.array([[0, 1, 2], [1, 2, 3]], dtype=np.int32)
points = np.array([[0, 0, 0], [1, 0, 0], [0, 1, 0], [1, 1, 0]], dtype=np.float32)
mesh = tf.Mesh(faces, points)

print(f"Mesh has {len(mesh.faces)} faces, {len(mesh.points)} points")
print(f"Mesh is {mesh.dims}D, ngon={mesh.ngon}")
```

## Transformations on Forms

Forms can be equipped with a transformation matrix, enabling queries on moving or transformed geometry without modifying the underlying data or rebuilding acceleration structures.

```python
import numpy as np

# Create a 3D transformation matrix (4x4 homogeneous)
# Translation by (5, 0, 0)
translation = np.eye(4, dtype=np.float32)
translation[:3, 3] = [5, 0, 0]

# Attach transformation when creating the form
mesh = tf.Mesh(faces, points, transformation=translation)

# Or set transformation later
mesh.transformation = translation

# Queries automatically use the transformation
d = tf.distance(mesh, other_mesh)  # Queries mesh in transformed pose

# 2D rotation + translation (3x3 homogeneous)
angle = np.radians(45)
transform_2d = np.array([
    [np.cos(angle), -np.sin(angle), 10],
    [np.sin(angle),  np.cos(angle), 20],
    [0,              0,               1]
], dtype=np.float32)

edge_mesh = tf.EdgeMesh(edges, points_2d, transformation=transform_2d)
```

All forms support transformations:
- **PointCloud**: Transforms points during spatial queries
- **EdgeMesh**: Transforms edges during spatial queries
- **Mesh**: Transforms faces during spatial queries

The transformation is applied internally during queries—the original data remains unchanged.

## Queries on Forms

Spatial queries extend the [core queries](/py/modules/core) from primitives to forms with spatial acceleration. All queries are supported on all combinations of forms and primitives, leveraging the spatial tree for efficient computation.

| **Query**                    | **Form-Primitive Returns**                      | **Form-Form Returns**                                  |
|------------------------------|-------------------------------------------------|--------------------------------------------------------|
| `distance` / `distance2`     | Distance (float)                                | Distance (float)                                       |
| `intersects`                 | Boolean                                         | Boolean                                                |
| `ray_cast`                   | `(element_id, t)` or `None`                     | N/A (ray-to-form only)                                 |
| `neighbor_search`            | `(idx, dist2, pt)` or list for KNN             | `((idx0, idx1), (dist2, pt0, pt1))`                    |
| `gather_intersecting_ids`    | Array of element IDs                            | Array of shape `(N, 2)` with ID pairs                  |
| `gather_ids_within_distance` | Array of element IDs                            | Array of shape `(N, 2)` with ID pairs                  |

### Distance

Compute distances using spatial acceleration:

#### Form-Primitive

```python
import trueform as tf

# PointCloud to segment distance
# Optionally add transformation for moving geometry
# point_cloud.transformation = transform_matrix
segment = tf.Segment([[0, 0, 0], [1, 1, 1]])
d = tf.distance(point_cloud, segment)

# EdgeMesh to AABB distance
aabb = tf.AABB(min=[0, 0], max=[1, 1])
d = tf.distance(edge_mesh, aabb)

# Mesh to polygon distance
polygon = tf.Polygon([[5, 5, 0], [6, 5, 0], [5.5, 6, 0]])
d = tf.distance(mesh, polygon)

# Use distance2 for faster comparisons (avoids sqrt)
d2 = tf.distance2(point_cloud, segment)
```

#### Form-Form

```python
# PointCloud to PointCloud distance
# Optionally add transformations to query moving geometry
# cloud1.transformation = transform1
# cloud2.transformation = transform2
d2 = tf.distance2(cloud1, cloud2)

# EdgeMesh to PointCloud distance
d = tf.distance(edge_mesh, point_cloud)

# Mesh to mesh distance
d = tf.distance(mesh1, mesh2)
```

### Intersects

Test for intersection between forms and primitives/forms:

#### Form-Primitive

```python
# PointCloud intersects segment
segment = tf.Segment([[0, 0, 0], [1, 1, 1]])
if tf.intersects(point_cloud, segment):
    print("PointCloud intersects segment")

# EdgeMesh intersects polygon
polygon = tf.Polygon([[0, 0], [2, 0], [1, 2]])
if tf.intersects(edge_mesh, polygon):
    print("EdgeMesh intersects polygon")

# Mesh intersects AABB
aabb = tf.AABB(min=[0, 0, 0], max=[1, 1, 1])
if tf.intersects(mesh, aabb):
    print("Mesh intersects bounding box")
```

#### Form-Form

```python
# PointCloud to PointCloud intersection
if tf.intersects(cloud1, cloud2):
    print("Point clouds overlap")

# EdgeMesh to PointCloud intersection
if tf.intersects(edge_mesh, point_cloud):
    print("EdgeMesh intersects point cloud")

# Mesh to mesh intersection
if tf.intersects(mesh1, mesh2):
    print("Meshes intersect")
```

### Ray Casting

Cast rays against forms to find intersected elements:

```python
ray = tf.Ray(origin=[0.5, 0.3, 2.0], direction=[0, 0, -1])
config = (0.0, 100.0)  # (min_t, max_t) tuple

# Cast ray against point cloud
result = tf.ray_cast(ray, point_cloud, config)
if result is not None:
    point_id, t = result
    hit_point = ray.origin + t * ray.direction
    print(f"Hit point {point_id} at t={t}")

# Cast ray against edge mesh
result = tf.ray_cast(ray, edge_mesh, config)
if result is not None:
    edge_id, t = result
    print(f"Hit edge {edge_id} at t={t}")

# Cast ray against mesh
result = tf.ray_cast(ray, mesh, config)
if result is not None:
    face_id, t = result
    print(f"Hit face {face_id} at t={t}")
```

## Neighbor Search

Find nearest neighbors in spatial structures. Supports K-nearest neighbors (KNN) and radius-based search.

### Form-Primitive

```python
# Find single nearest neighbor to a primitive
query = tf.Point([0.5, 0.5, 0.5])
idx, dist2, pt = tf.neighbor_search(mesh, query)
print(f"Nearest face: {idx}, distance: {np.sqrt(dist2)}")

# K-nearest neighbors (find 10 nearest)
query = tf.Segment([[1, 2, 3], [2, 3, 4]])
neighbors = tf.neighbor_search(mesh, query, k=10)
# Returns list of (index, distance_squared, closest_point) tuples
for idx, dist2, pt in neighbors:
    print(f"Face {idx} at distance {np.sqrt(dist2)}")

# Radius search (within distance threshold)
polygon = tf.Polygon([[0, 0], [1, 0], [0.5, 1]])
result = tf.neighbor_search(edge_mesh, polygon, radius=2.0)
# Returns None if no element within radius

# KNN with radius limit
neighbors = tf.neighbor_search(point_cloud, query, k=10, radius=5.0)
# Returns up to 10 neighbors within radius 5.0
```

### Form-Form

```python
# PointCloud to PointCloud nearest neighbor
result = tf.neighbor_search(cloud1, cloud2)
if result is not None:
    (idx0, idx1), (dist2, pt0, pt1) = result
    print(f"Closest: point {idx0} in cloud1 to point {idx1} in cloud2")

# EdgeMesh to PointCloud nearest neighbor
result = tf.neighbor_search(edge_mesh, point_cloud)
if result is not None:
    (edge_id, point_id), (dist2, pt_on_edge, pt_on_cloud) = result

# Mesh to Mesh nearest neighbor
result = tf.neighbor_search(mesh1, mesh2)
if result is not None:
    (idx0, idx1), (dist2, pt0, pt1) = result
    print(f"Closest: face {idx0} in mesh1 to face {idx1} in mesh2")
```

## Spatial Filtering

Gather element IDs based on spatial criteria (intersection or distance threshold).

### Gather Intersecting IDs

#### Form-Primitive

```python
# Find all points that intersect a segment
segment = tf.Segment([[0, 0, 0], [1, 1, 1]])
ids = tf.gather_intersecting_ids(point_cloud, segment)
# Returns array of point indices

# Find all edges that intersect a polygon
polygon = tf.Polygon([[0, 0], [2, 0], [1, 2]])
ids = tf.gather_intersecting_ids(edge_mesh, polygon)
# Returns array of edge indices

# Find all mesh faces that intersect with an AABB
aabb = tf.AABB(min=[0, 0, 0], max=[1, 1, 1])
ids = tf.gather_intersecting_ids(mesh, aabb)
# Returns array of face indices, e.g., [0, 3, 5]
```

#### Form-Form

```python
# PointCloud to PointCloud intersections
pairs = tf.gather_intersecting_ids(cloud1, cloud2)
# Returns shape (N, 2): [[point_id1, point_id2], ...]

# EdgeMesh to PointCloud intersections
pairs = tf.gather_intersecting_ids(edge_mesh, point_cloud)
# Returns shape (N, 2): [[edge_id, point_id], ...]

# Find intersecting pairs between forms (returns Nx2 array)
pairs = tf.gather_intersecting_ids(mesh, edge_mesh)
# Returns shape (N, 2): [[face_id, edge_id], ...]
for face_id, edge_id in pairs:
    print(f"Face {face_id} intersects edge {edge_id}")
```

### Gather IDs Within Distance

#### Form-Primitive

```python
# Find points within distance of a segment
segment = tf.Segment([[0, 0, 0], [1, 1, 1]])
ids = tf.gather_ids_within_distance(point_cloud, segment, distance=0.5)
# Returns array of point indices within distance

# Find edges within distance of a polygon
polygon = tf.Polygon([[0, 0], [1, 0], [0.5, 1]])
ids = tf.gather_ids_within_distance(edge_mesh, polygon, distance=0.5)

# Find mesh elements within distance of a point
query = tf.Point([1.0, 1.0, 1.0])
ids = tf.gather_ids_within_distance(mesh, query, distance=2.0)
# Returns array of face indices within distance
```

#### Form-Form

```python
# PointCloud to PointCloud within distance
pairs = tf.gather_ids_within_distance(cloud1, cloud2, distance=0.5)
# Returns shape (N, 2): [[point_id1, point_id2], ...]

# EdgeMesh to EdgeMesh within distance
pairs = tf.gather_ids_within_distance(edge_mesh1, edge_mesh2, distance=1.0)
# Returns shape (N, 2): [[edge_id1, edge_id2], ...]

# Gather pairs between forms within distance
pairs = tf.gather_ids_within_distance(mesh, point_cloud, distance=0.5)
# Returns shape (N, 2): [[face_id, point_id], ...]
```

## Distance Fields

Compute vectorized distances from many points to a primitive:

```python
# Distance from points to a polygon
query_points = np.random.rand(1000, 3).astype(np.float32)
polygon = tf.Polygon([[0, 0, 0], [1, 0, 0], [0.5, 1, 0]])
distances = tf.distance_field(query_points, polygon)
# Returns array of shape (1000,) with unsigned distances

# Signed distance to a plane (negative inside, positive outside)
plane = tf.Plane(normal=[0, 0, 1], origin=[0, 0, 5])
signed_distances = tf.distance_field(query_points, plane)

# Works with PointCloud input too
cloud = tf.PointCloud(query_points)
distances = tf.distance_field(cloud, plane)
```
