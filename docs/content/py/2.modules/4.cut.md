The Cut module provides boolean operations on meshes and scalar field cutting.

## Boolean Operations

Boolean operations combine two meshes using set operations.

### Input Mesh Requirements

Boolean operations support a superset of PWN (piecewise winding number) meshes. Valid inputs are **PWN + non-manifold flaps + geometric inconsistencies**.

**Theoretical Foundation:**

The method operates on meshes whose intersection graphs possess the *splitting property* (Definition 10 in the [paper](/about/publications)). PWN meshes are handled deterministically, while non-PWN properties are modeled as stochastic noise on the underlying PWN mesh, with classification handled by a Bayesian approach. This achieves **commutative correctness**: Boolean operations commute with mesh idealization, allowing workflows to defer cleanup until the final step.

::tip{icon="i-lucide-book"}
For the splitting property definition, stochastic formulation, and robustness validation, see *Real-Time Mesh Booleans that Commute with Mesh Idealization* in [Publications](/about/publications).
::

### Union

Compute the union of two meshes:

```python
import trueform as tf

# Boolean union: A ∪ B
result = tf.boolean_union(mesh_a, mesh_b)

# Result is a Mesh containing the union
```

### Intersection

Compute the intersection of two meshes:

```python
# Boolean intersection: A ∩ B
result = tf.boolean_intersection(mesh_a, mesh_b)
```

### Difference

Compute the difference between two meshes:

```python
# Boolean difference: A \ B
result = tf.boolean_difference(mesh_a, mesh_b)
```

All boolean operations return a new `Mesh` object.

## Isobands

Extract regions between isocontour levels from scalar fields:

```python
# Create scalar field (one value per vertex)
scalar_field = np.random.rand(len(mesh.points)).astype(np.float32)

# Define isoband levels
levels = np.array([0.2, 0.4, 0.6, 0.8], dtype=np.float32)

# Extract specific bands (e.g., band 0: [-∞, 0.2), band 2: [0.4, 0.6))
band_indices = np.array([0, 2], dtype=np.int32)
result = tf.isobands(mesh, scalar_field, levels, band_indices)

# Result is a Mesh containing only the selected bands
```

Isobands are useful for:
- Extracting elevation ranges from terrain
- Segmenting meshes by property values
- Creating multi-level representations

::tip{icon="i-lucide-info"}
For extracting isocontour curves without cutting the mesh, see [Intersect](/py/modules/intersect). For implementation details, see the [C++ Cut](/cpp/modules/cut) documentation.
::
