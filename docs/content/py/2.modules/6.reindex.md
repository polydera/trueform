The Reindex module provides tools for extracting, filtering, and reorganizing geometric data while maintaining referential integrity.

## Core Concepts

Reindexing in trueform maintains two key guarantees:

1. **Index Maps**: Mapping between old and new indices for efficient data reorganization
2. **Referential Integrity**: Relationships between data structures (e.g., faces and points) remain consistent after reindexing

All reindexing operations automatically remap indices to maintain these guarantees.

## Reindex by IDs

Extract specific elements by their indices:

```python
import trueform as tf
import numpy as np

# Extract specific faces from mesh
face_ids = np.array([0, 5, 10, 15], dtype=np.int32)
subset_mesh = tf.reindex_by_ids(mesh, face_ids)

# Extract specific edges from edge mesh
edge_ids = np.array([2, 4, 6], dtype=np.int32)
subset_edges = tf.reindex_by_ids(edge_mesh, edge_ids)

# Works with raw tuple data too
faces = np.array([[0, 1, 2], [1, 2, 3], [2, 3, 4]], dtype=np.int32)
points = np.array([[0, 0], [1, 0], [1, 1], [0, 1], [0.5, 0.5]], dtype=np.float32)
ids = np.array([0, 2], dtype=np.int32)
subset_faces, subset_points = tf.reindex_by_ids((faces, points), ids)
```

The result contains only the specified elements and their referenced points, with indices remapped to maintain referential integrity.

## Reindex by Mask

Filter elements using a boolean mask:

```python
# Create boolean mask (one per face)
mask = np.zeros(len(mesh.faces), dtype=bool)
mask[::2] = True  # Keep every other face

# Extract faces where mask is True
filtered_mesh = tf.reindex_by_mask(mesh, mask)

# Filter by geometric criteria
areas = np.array([compute_area(face) for face in mesh.faces])
large_faces = areas > 0.1
filtered_mesh = tf.reindex_by_mask(mesh, large_faces)

# Works with edge meshes
mask = np.ones(len(edge_mesh.edges), dtype=bool)
mask[10:20] = False  # Remove edges 10-19
filtered_edges = tf.reindex_by_mask(edge_mesh, mask)
```

## Concatenate

Merge multiple geometries into a single structure:

```python
# Concatenate meshes
combined_faces, combined_points = tf.concatenated([mesh1, mesh2, mesh3])
combined_mesh = tf.Mesh(combined_faces, combined_points)

# Concatenate edge meshes
combined_edges, combined_points = tf.concatenated([edges1, edges2])
combined_edge_mesh = tf.EdgeMesh(combined_edges, combined_points)

# Also accepts tuples of (indices, points)
data = [(faces1, points1), (faces2, points2)]
combined_faces, combined_points = tf.concatenated(data)

# Example: Build composite mesh from multiple sources
meshes = [
    tf.Mesh(faces1, points1),
    tf.Mesh(faces2, points2),
    tf.Mesh(faces3, points3)
]
all_faces, all_points = tf.concatenated(meshes)
composite = tf.Mesh(all_faces, all_points)
```

The function automatically handles index offsetting to maintain referential integrity. All input geometries must have the same:
- Vertices per primitive (e.g., all triangles or all quads)
- Point dimensions (e.g., all 2D or all 3D)

## Split into Components

Split a mesh into connected components based on labels:

```python
# Create labels (one per face, e.g., from connected component analysis)
labels = np.array([0, 0, 1, 1, 2, 2], dtype=np.int32)

# Split into separate meshes
components = tf.split_into_components(mesh, labels)

# components is a list of Mesh objects, one per unique label
print(f"Split into {len(components)} components")

for i, component in enumerate(components):
    print(f"Component {i}: {len(component.faces)} faces")

# Works with edge meshes too
edge_labels = np.array([0, 0, 0, 1, 1, 1, 2, 2], dtype=np.int32)
edge_components = tf.split_into_components(edge_mesh, edge_labels)

# Example: Separate disconnected regions
from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import connected_components

# Build adjacency from mesh topology
n_faces = len(mesh.faces)
adjacency = build_face_adjacency(mesh)  # Your adjacency builder
n_components, component_labels = connected_components(adjacency)

# Split into separate meshes
separated = tf.split_into_components(mesh, component_labels)
print(f"Mesh has {n_components} disconnected regions")
```

This is the inverse of concatenation: splits a single mesh with per-element labels into multiple separate meshes.
