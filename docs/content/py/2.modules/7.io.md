The I/O module provides functions for reading and writing mesh data in STL format.

## read_stl

Read an STL file and return mesh data as numpy arrays.

```python
def read_stl(filename: str, index_dtype: Union[type, np.dtype] = np.int32) -> Tuple[np.ndarray, np.ndarray]
```

**Parameters:**
- `filename` (str): Path to STL file
- `index_dtype` (dtype, optional): Index type for faces (`np.int32` or `np.int64`), default `np.int32`

**Returns:**
- `faces`: ndarray of shape `(N, 3)` with dtype `index_dtype`
- `points`: ndarray of shape `(M, 3)` with dtype `np.float32`

**Key Features:**
- Reads both ASCII and binary STL files automatically
- Cleans duplicate vertices
- Returns zero-copy numpy arrays
- Face indices are 0-based

**Examples:**

```python
import trueform as tf
import numpy as np

# Read STL file (default int32 indices)
faces, points = tf.read_stl("model.stl")
mesh = tf.Mesh(faces, points)

print(f"Loaded mesh: {len(faces)} faces, {len(points)} vertices")

# For large meshes, use int64 indices
faces, points = tf.read_stl("large_model.stl", index_dtype=np.int64)
large_mesh = tf.Mesh(faces, points)
```

## write_stl

Write mesh data to binary STL format.

```python
def write_stl(
    data: Union[Tuple[np.ndarray, np.ndarray], Mesh],
    filename: str,
    transformation: Optional[np.ndarray] = None
) -> bool
```

**Parameters:**
- `data`: Either a tuple `(faces, points)` or a `Mesh` object
  - `faces`: ndarray of shape `(N, 3)` with dtype `np.int32` or `np.int64`
  - `points`: ndarray of shape `(M, 3)` with dtype `np.float32`
- `filename` (str): Output path (`.stl` extension auto-appended if missing)
- `transformation` (optional): `(4, 4)` homogeneous transformation matrix (dtype `np.float32`)

**Returns:**
- `bool`: `True` on success, `False` on failure

**Transformation Priority:**
1. Explicit `transformation` kwarg (highest priority)
2. `Mesh.transformation` property (if `Mesh` object provided)
3. No transformation (default)

**Validation Requirements:**
- Faces: shape `(N, 3)`, dtype `np.int32` or `np.int64`
- Points: shape `(M, 3)`, dtype `np.float32`
- Transformation: shape `(4, 4)`, dtype `np.float32` (if provided)
- Mesh objects: `dims == 3`, `ngon == 3` (triangular only)

**Examples:**

```python
import trueform as tf
import numpy as np

# Write from tuple (faces, points)
faces = np.array([[0, 1, 2]], dtype=np.int32)
points = np.array([[0, 0, 0], [1, 0, 0], [0, 1, 0]], dtype=np.float32)
tf.write_stl((faces, points), "triangle.stl")

# Write Mesh object
mesh = tf.Mesh(faces, points)
tf.write_stl(mesh, "triangle_mesh.stl")

# Apply transformation during write
transform = np.eye(4, dtype=np.float32)
transform[:3, 3] = [10, 0, 5]  # Translate by (10, 0, 5)
tf.write_stl(mesh, "translated.stl", transformation=transform)

# Mesh with transformation property
mesh.transformation = transform
tf.write_stl(mesh, "mesh_with_transform.stl")

# Override mesh transformation
other_transform = np.eye(4, dtype=np.float32)
other_transform[2, 3] = 20  # Different Z translation
tf.write_stl(mesh, "overridden.stl", transformation=other_transform)
```

## Round-trip Example

Read, modify, and write back:

```python
import trueform as tf
import numpy as np

# Read STL file
faces, points = tf.read_stl("input.stl")

# Create transformation (scale by 2, rotate around Z)
scale = 2.0
angle = np.pi / 4  # 45 degrees
transform = np.eye(4, dtype=np.float32)
transform[0, 0] = scale * np.cos(angle)
transform[0, 1] = -scale * np.sin(angle)
transform[1, 0] = scale * np.sin(angle)
transform[1, 1] = scale * np.cos(angle)
transform[2, 2] = scale

# Write with transformation
tf.write_stl((faces, points), "scaled_rotated.stl", transformation=transform)

# Or use Mesh object with transformation
mesh = tf.Mesh(faces, points)
mesh = tf.transformed(mesh, transform)
tf.write_stl(mesh, "scaled_rotated_alt.stl")
```
