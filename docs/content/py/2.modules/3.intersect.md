The Intersect module computes intersection curves between geometric objects and extracts isocontours from scalar fields.

## Intersection Curves

Compute intersection curves between two meshes:

```python
import trueform as tf
import numpy as np

# Compute intersection curves between two meshes
curves = tf.intersection_curves(mesh1, mesh2)

# curves is an EdgeMesh representing the intersection
print(f"Number of curve segments: {len(curves.edges)}")
print(f"Number of curve points: {len(curves.points)}")
```

The intersection curves form an `EdgeMesh` where edges represent the curve segments and points are the intersection vertices.

## Isocontours

Extract isocontour curves from scalar fields on meshes:

```python
# Create scalar field (one value per vertex)
scalar_field = np.random.rand(len(mesh.points)).astype(np.float32)

# Extract isocontours at specific values
iso_values = np.array([0.3, 0.5, 0.7], dtype=np.float32)
contours = tf.isocontours(mesh, scalar_field, iso_values)

# contours is an EdgeMesh where each edge is part of an isocontour
```

Use cases for isocontours:
- Extracting elevation contours from terrain data
- Visualizing level sets of physical quantities
- Creating contour lines from implicit functions
