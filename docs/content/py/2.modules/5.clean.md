The Clean module removes unwanted elements from geometric data.

## Cleaned

Remove duplicates, degenerate elements, and unreferenced points:

```python
import trueform as tf

# Clean a mesh
cleaned_mesh = tf.cleaned(mesh)

# Clean an edge mesh
cleaned_edges = tf.cleaned(edge_mesh)

# Clean a point cloud
cleaned_points = tf.cleaned(point_cloud)
```

### What Gets Removed

The `cleaned` function removes:

- **Duplicate vertices**: Points at the same location are merged
- **Duplicate faces/edges**: Identical topology is deduplicated
- **Degenerate elements**: Zero-area triangles, zero-length edges
- **Unreferenced points**: Vertices not used by any face/edge

This is useful for:
- Preparing meshes for downstream algorithms
- Reducing memory usage
- Fixing numerical artifacts from boolean operations
- Consolidating merged geometries
