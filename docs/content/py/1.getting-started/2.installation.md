## Requirements

- **Python 3.8** or later

## PyPI

```bash
pip install trueform
```

## Building from Source

```bash
cmake -B build-python -DTF_BUILD_PYTHON=ON
cmake --build build-python --target python
```

Then install:

```bash
pip install ./build-python/python
```

## Verify

```python
import trueform as tf

print(tf.__version__)
```
