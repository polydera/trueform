## Minimal, Expressive Primitives

```cpp [primitives.cpp]
std::vector<float> raw_points = { 0, 0, 0, 1, 0, 0, 0, 1, 0 };
std::vector<int> triangle_indices = { 0, 1, 2 };
auto pts = tf::make_points<3>(raw_points);
auto triangles = tf::make_polygons(tf::make_blocked_range<3>(triangle_indices), pts);

// Enrich with policies
std::vector<std::string_view> ids = {"a"};
std::vector<float> raw_normals = {0, 0, 1};
std::vector<float> raw_directions = {1.f, 0.f, 0.f};
std::vector<std::string_view> labels = {"label_A"};

auto enriched_triangles = triangles
  | tf::zip_ids(ids)
  | tf::zip_normals(tf::make_unit_vectors<3>(raw_normals))
  | tf::zip_states(tf::make_vectors<3>(raw_directions), labels);
```

## Spatial: Trees and Forms

```cpp [spatial.cpp]
// Build a tree and wrap as a form
tf::tree<int, float, 3> tree(triangles, tf::config_tree(4, 4));
auto static_form = tf::make_form(tree, triangles);

// Dynamic form with a frame
auto frame = tf::random_transformation<float, 3>();
auto dynamic_form = tf::make_form(frame, tree, triangles);

// Intersections between forms
std::vector<std::pair<int, int>> intersecting_ids;
tf::gather_ids(static_form, dynamic_form, tf::intersects_f, std::back_inserter(intersecting_ids));
```

## Neighbor Search (kNN)

```cpp [knn.cpp]
auto query_pt = tf::random_point<float, 3>();
std::array<tf::nearest_neighbor<int, float, 3>, 10> buffer;
auto knn = tf::make_nearest_neighbors(buffer.begin(), 10/*, search_radius*/);

tf::neighbor_search(static_form, query_pt, knn);
for (auto [primitive_id, metric_point] : knn) {
  auto [distance2, closest_pt] = metric_point;
}
```

## Ray Casting

```cpp [ray.cpp]
auto ray = tf::make_ray_between_points(tf::random_point<float, 3>(), tf::random_point<float, 3>());
if (auto hit = tf::ray_hit(ray, static_form, tf::make_ray_config(0.f, 1e6f))) {
  auto [primitive_id, data] = *hit;
  auto [status, t, point] = data;
}
```

## Intersections

### Scalar Field Slicing

```cpp [sfi.cpp]
tf::scalar_field_intersections<int, float, 3> sfi;
std::vector<float> scalar_field(triangles.points().size());
sfi.build(triangles, scalar_field, /*cut_value*/ 0.0f);
auto edges = tf::make_intersection_edges(sfi);
auto segments = tf::make_segments(edges, sfi.intersection_points());
```

### Mesh-Mesh (Forms) Intersection

```cpp [forms_intersections.cpp]
tf::forms_intersections<int, double, 3> fi;
fi.build(static_form, dynamic_form);
auto edges = tf::make_intersection_edges(fi);
auto segments = tf::make_segments(edges, fi.intersection_points());
```
