`trueform` is a C++ header-only library for real-time geometric processing, built on composable views and inline policy injection. Operate directly on your data with semantic primitives and ranges; build spatial trees and forms for fast queries.

## Key Features

- **Minimal primitives**: points, vectors, lines, rays, segments, polygons, AABBs.
- **Composable policies**: tag/zip `id`, `normal`, `state` onto primitives and ranges.
- **Spatial trees and forms**: fast k-NN, intersections, ray casts, and search.
- **Topology**: connectivity structures and planar embeddings.
- **Intersections**: planar arrangements, scalar slicing, mesh-mesh curves.
