Benchmarks for `tf::tree` construction and spatial queries. Reported times are mean wall-clock measurements. Test meshes are variants of the [Stanford Dragon](https://github.com/xlabmedical/trueform/tree/main/benchmarks/data) remeshed to 58K–1M polygons.

## Point Clouds

### Tree Construction

Construction time for spatial index structures over mesh vertices. TrueForm builds trees with AABB, OBB, and OBBRSS bounding volumes; [nanoflann](https://github.com/jlblancoc/nanoflann) builds a k-d tree. Each configuration is measured 10 times; the mean is reported.

Source: [TrueForm](https://github.com/xlabmedical/trueform/blob/main/benchmarks/spatial/point_cloud-build_tree-tf-impl.cpp), [nanoflann](https://github.com/xlabmedical/trueform/blob/main/benchmarks/spatial/point_cloud-build_tree-nanoflann-impl.cpp)

::ChartsSpatialPointCloudBuildSpeedup{class="my-12"}

TrueForm AABB tree construction is 7× faster than nanoflann's k-d tree at 1M points, while also supporting OBB and OBBRSS bounding volumes.

### k-Nearest Neighbor

Query time for k nearest neighbors. Query points are generated by adding uniform random offsets (within 1% of bounding box diagonal) to mesh vertices. For each mesh size, 1000 queries are executed; the mean time per query is reported. Results shown for k=10.

Source: [TrueForm](https://github.com/xlabmedical/trueform/blob/main/benchmarks/spatial/point_cloud-knn-tf-impl.cpp), [nanoflann](https://github.com/xlabmedical/trueform/blob/main/benchmarks/spatial/point_cloud-knn-nanoflann-impl.cpp)

::ChartsSpatialKnnSpeedup{class="my-12"}

TrueForm k-NN queries are 3× faster than nanoflann at 500K points.

## Polygon Meshes

### BVH Construction

Construction time for bounding volume hierarchies over triangle meshes. TrueForm trees use arity 4 and leaf size 4. Each configuration is measured 10 times; the mean is reported.

#### AABB

Tree using [axis-aligned bounding boxes](https://en.wikipedia.org/wiki/Bounding_volume#Common_types). TrueForm is compared against [CGAL](https://www.cgal.org/) AABB trees and [FCL](https://github.com/flexible-collision-library/fcl).

Source: [TrueForm](https://github.com/xlabmedical/trueform/blob/main/benchmarks/spatial/polygons-build_tree-tf-impl.cpp), [CGAL](https://github.com/xlabmedical/trueform/blob/main/benchmarks/spatial/polygons-build_tree-cgal-impl.cpp), [FCL](https://github.com/xlabmedical/trueform/blob/main/benchmarks/spatial/polygons-build_tree-fcl-impl.cpp)

### Mesh-to-Mesh Distance

Minimum distance computation between two copies of the same mesh. The second mesh is placed at a random rigid transform sampled uniformly within a sphere of radius equal to twice the bounding box diagonal. For each mesh size, 1000 random configurations are evaluated; the mean query time is reported. TrueForm uses `tf::neighbor_search` on polygon forms; [FCL](https://github.com/flexible-collision-library/fcl) uses `MeshDistanceTraversalNode`.

#### AABB

Using [axis-aligned bounding boxes](https://en.wikipedia.org/wiki/Bounding_volume#Common_types).

Source: [TrueForm](https://github.com/xlabmedical/trueform/blob/main/benchmarks/spatial/polygons_to_polygons-closest_point-tf-impl.cpp), [FCL](https://github.com/xlabmedical/trueform/blob/main/benchmarks/spatial/polygons_to_polygons-closest_point-fcl-impl.cpp)

#### OBBRSS

Using a hybrid of oriented bounding boxes and [rectangle swept spheres](https://gamma.cs.unc.edu/SSV/).

Source: [TrueForm](https://github.com/xlabmedical/trueform/blob/main/benchmarks/spatial/polygons_to_polygons-closest_point-tf-impl.cpp), [FCL](https://github.com/xlabmedical/trueform/blob/main/benchmarks/spatial/polygons_to_polygons-closest_point-fcl-impl.cpp)
