TrueForm enables real-time geometric operations on million-polygon meshes. On a pair of 1M-polygon meshes, boolean union completes in 27ms and intersection curve extraction in 5ms. [Try it live in your browser →](/live-examples/boolean)

These benchmarks quantify performance against established libraries across spatial indexing, topology analysis, intersection computation, and mesh cutting.

## Experimental Setup

| Property | Value |
|----------|-------|
| CPU | Apple M-series (16 cores) |
| Compiler | Clang with `-O3` |
| Test Data | [Stanford Dragon](https://github.com/xlabmedical/trueform/tree/main/benchmarks/data), 58K–1M polygons |
| Sampling | 10–1000 evaluations per configuration |

Construction benchmarks use 10 runs; query benchmarks use 1000. All libraries use parallel execution where available. Reported times are mean wall-clock measurements. [Source code →](https://github.com/xlabmedical/trueform/tree/main/benchmarks)

## Summary

Peak performance at maximum mesh size (see detailed results below):

| Operation | Input | Time | Speedup | Baseline |
|-----------|-------|------|---------|----------|
| Boolean Union | 2 × 1M | 27 ms | **61×** | CGAL |
| Mesh–Mesh Curves | 2 × 1M | 5.5 ms | **156×** | CGAL |
| Self-Intersection | 2 × 1M | 112 ms | **46×** | libigl |
| Isocontours | 1M, 16 cuts | 4.2 ms | **40×** | VTK |
| Connected Components | 1M | 16 ms | **11×** | CGAL |
| Boundary Paths | 1M | 12 ms | **12×** | CGAL |
| k-NN Query | 500K points | 1.7 µs | **3×** | nanoflann |
| Mesh–Mesh Distance | 2 × 1M | 0.2 ms | **2×** | FCL |

## Running Benchmarks

```bash
brew install boost gmp mpfr libccd tbb
cmake -B build -DBUILD_BENCHMARKS=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build --target benchmarks
./build/run-benchmarks
```

Results are written to `build/results/`. Use `consolidate_results.py` to merge per-library CSVs.
