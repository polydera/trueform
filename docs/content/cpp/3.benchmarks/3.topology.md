Benchmarks for mesh connectivity analysis. Reported times are mean wall-clock measurements over 10 runs. Test meshes are variants of the [Stanford Dragon](https://github.com/xlabmedical/trueform/tree/main/benchmarks/data) remeshed to 58K–1M polygons.

## Connected Components

Labeling of face-connected components. Topology is computed from scratch for each run. TrueForm uses `tf::make_manifold_edge_connected_component_labels`; [VTK](https://vtk.org/) uses `vtkPolyDataConnectivityFilter`; [CGAL](https://www.cgal.org/) uses `CGAL::Polygon_mesh_processing::connected_components`; [libigl](https://libigl.github.io/) uses `igl::facet_components`.

Source: [TrueForm](https://github.com/xlabmedical/trueform/blob/main/benchmarks/topology/connected_components-tf-impl.cpp), [VTK](https://github.com/xlabmedical/trueform/blob/main/benchmarks/topology/connected_components-vtk-impl.cpp), [CGAL](https://github.com/xlabmedical/trueform/blob/main/benchmarks/topology/connected_components-cgal-impl.cpp), [libigl](https://github.com/xlabmedical/trueform/blob/main/benchmarks/topology/connected_components-igl-impl.cpp)

TrueForm connected component labeling is 11× faster than CGAL, 17× faster than libigl, and 5× faster than VTK at 1M polygons.

## Boundary Paths

Extraction of boundary edges organized into connected paths. Topology is computed from scratch for each run. TrueForm uses `tf::make_boundary_paths`; VTK uses `vtkFeatureEdges`; CGAL uses `CGAL::Polygon_mesh_processing::extract_boundary_cycles`; libigl uses `igl::boundary_loop`.

Source: [TrueForm](https://github.com/xlabmedical/trueform/blob/main/benchmarks/topology/boundary_paths-tf-impl.cpp), [VTK](https://github.com/xlabmedical/trueform/blob/main/benchmarks/topology/boundary_paths-vtk-impl.cpp), [CGAL](https://github.com/xlabmedical/trueform/blob/main/benchmarks/topology/boundary_paths-cgal-impl.cpp), [libigl](https://github.com/xlabmedical/trueform/blob/main/benchmarks/topology/boundary_paths-igl-impl.cpp)
