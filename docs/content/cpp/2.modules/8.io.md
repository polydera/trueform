The I/O module provides functions for reading and writing mesh data in STL format.

## read_stl

Read an STL file (binary or ASCII) and return a cleaned mesh.

```cpp
template <typename Index>
auto read_stl(std::string_view file_path) -> tf::polygons_buffer<Index, float, 3, 3>
```

**Template Parameters:**
- `Index`: Index type for face connectivity (typically `int` or `int64_t`)

**Parameters:**
- `file_path`: Path to STL file

**Returns:**
- `tf::polygons_buffer<Index, float, 3, 3>`: Triangular mesh with deduplicated vertices

**Key Features:**
- Automatically detects binary vs ASCII format
- Cleans duplicate vertices via `tf::clean::polygon_soup`
- Returns 3D triangular mesh (float coordinates)

**Example:**

```cpp
#include <trueform/io.hpp>

// Read with int32 indices (default for most cases)
auto mesh = tf::read_stl<int>("model.stl");

// Read with int64 indices (for very large meshes)
auto large_mesh = tf::read_stl<int64_t>("large_model.stl");

// Access mesh data
auto faces = mesh.primitives();     // (N, 3) connectivity
auto points = mesh.points();        // (M, 3) vertex positions
```

## write_stl

Write a mesh to binary STL format.

```cpp
template <typename Policy>
auto write_stl(const tf::polygons<Policy> &polygons, std::string filename) -> bool
```

**Parameters:**
- `polygons`: Polygon mesh (must be 3D triangular)
- `filename`: Output path (`.stl` extension auto-appended if missing)

**Returns:**
- `bool`: `true` on success, `false` on failure

**Requirements:**
- Must be 3D mesh: `tf::coordinate_dims_v<Policy> == 3`
- Must be triangular: `tf::static_size_v<polygon_t> == 3`

**Transformation Support:**

If the mesh has a frame policy, transformations are automatically applied to vertices and normals:

```cpp
#include <trueform/io.hpp>
#include <trueform/core.hpp>

// Read mesh
auto mesh = tf::read_stl<int>("input.stl");

// Apply transformation
auto translation = tf::translation(tf::vec3{10.0f, 0.0f, 0.0f});
auto transformed = tf::transformed(mesh, translation);

// Write transformed mesh (transformation applied automatically)
tf::write_stl(transformed, "output.stl");
```

**Normal Support:**

Normals are written if available via normals policy, otherwise zero normals are written.

**Performance:**

- Files < 500MB: Parallel buffered approach (fills entire file in parallel)
- Files ≥ 500MB: Sequential streaming approach

**File Format:**

Writes binary STL format:
- 80-byte header
- 4-byte triangle count (uint32)
- 50 bytes per triangle (12 normal + 36 vertices + 2 attribute bytes)

**Example:**

```cpp
#include <trueform/io.hpp>
#include <trueform/core.hpp>

// Round-trip: read, transform, write
auto mesh = tf::read_stl<int>("input.stl");

// Create transformation matrix
auto scale = tf::scaling(tf::vec3{2.0f, 2.0f, 2.0f});
auto rotation = tf::rotation(tf::vec3{0.0f, 0.0f, 1.0f}, 3.14159f / 4.0f);
auto transform = scale * rotation;

// Apply and write
auto result = tf::transformed(mesh, transform);
bool success = tf::write_stl(result, "scaled_rotated.stl");
```
