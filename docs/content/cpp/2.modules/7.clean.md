The Clean module provides high-performance tools for removing duplicate, degenerate, and unreferenced elements from geometric data. It operates directly on `trueform`'s primitive ranges and automatically maintains referential integrity across complex data structures while providing optional index maps for downstream processing.

Include the module with:

```cpp
#include <trueform/clean.hpp>
```

## Core Concepts

Cleaning in `trueform` addresses several common geometric data quality issues:

1. **Duplicate Points**: Multiple vertices at the same spatial location
2. **Degenerate Elements**: Zero-area polygons or zero-length segments
3. **Unreferenced Points**: Vertices not used by any primitive
4. **Soup vs. Structured Data**: Different cleaning strategies based on data organization

The module provides both immediate cleaning operations and optional index map returns for tracking transformations.

### Index Type Deduction

For indexed data (polygons, segments, curves), the index type is automatically deduced from the input:

```cpp
// Index type deduced from polygons.faces()[0][0]
auto clean = tf::cleaned(polygons);

// Explicit index type when needed (e.g., large meshes)
auto clean = tf::cleaned<int64_t>(polygons);
```

For points and polygon/segment soups (which have no indices to deduce from), the index type defaults to `int`:

```cpp
// Index defaults to int
auto clean_points = tf::cleaned(points);
auto clean_soup = tf::cleaned(polygon_soup);

// Explicit index for large data
auto clean_points = tf::cleaned<int64_t>(points);
```

## Basic Cleaning Operations

### Point Cleaning

Remove duplicate points from point collections:

```cpp [point_cleaning.cpp]
// Basic point cleaning - removes exact duplicates
// Index defaults to int (points have no index to deduce from)
auto clean_points = tf::cleaned(points);

// Tolerance-based cleaning - merges points within distance
float tolerance = 1e-6f;
auto clean_points = tf::cleaned(points, tolerance);

// Explicit index type for large point clouds
auto clean_points = tf::cleaned<int64_t>(points);

// Get index map for downstream processing
auto [clean_points, point_map] = tf::cleaned(points, tolerance, tf::return_index_map);

// Reindex associated data using the map
auto clean_normals = tf::reindexed(point_normals, point_map);
auto clean_attributes = tf::reindexed(tf::make_range(point_attributes), point_map);
```

### Segment Cleaning

Clean segment collections by removing duplicates, degenerates, and unreferenced points:

```cpp [segment_cleaning.cpp]
// Clean segments - Index deduced from segments.edges()[0][0]
auto clean_segments = tf::cleaned(segments);

// Tolerance-based segment cleaning
float tolerance = 1e-5f;
auto clean_segments = tf::cleaned(segments, tolerance);

// Explicit index type
auto clean_segments = tf::cleaned<int64_t>(segments);

// Get both edge and point index maps
auto [clean_segments, edge_map, point_map] =
    tf::cleaned(segments, tolerance, tf::return_index_map);

// Reindex edge and point attributes
auto clean_edge_attrs = tf::reindexed(tf::make_edges(edge_attrs), edge_map);
auto clean_point_attrs = tf::reindexed(point_attrs, point_map);
```

### Curve Cleaning

Clean curve collections (connected paths) by merging points, removing degenerate edges, and reconnecting into continuous paths:

```cpp [curve_cleaning.cpp]
// Clean curves - Index deduced from curves.paths()[0][0]
auto clean_curves = tf::cleaned(curves);

// Tolerance-based curve cleaning
float tolerance = 1e-5f;
auto clean_curves = tf::cleaned(curves, tolerance);

// Get point index map (edge map not available since paths are reconnected)
auto [clean_curves, point_map] = tf::cleaned(curves, tolerance, tf::return_index_map);

// Reindex point attributes
auto clean_point_attrs = tf::reindexed(point_attrs, point_map);
```

::note{icon="i-lucide-info"}
Unlike segment cleaning, curve cleaning only returns a point index map. Edge/cell mapping is not available because edges are reconnected into new paths after cleaning, changing the topology.
::

### Polygon Cleaning

Clean mesh data by removing duplicates, degenerate faces, and unreferenced vertices:

```cpp [polygon_cleaning.cpp]
// Clean polygons - Index deduced from polygons.faces()[0][0]
auto clean_polygons = tf::cleaned(polygons);

// Tolerance-based polygon cleaning
double tolerance = 1e-8;
auto clean_polygons = tf::cleaned(polygons, tolerance);

// Explicit index type for large meshes
auto clean_polygons = tf::cleaned<int64_t>(polygons);

// Get both face and point index maps
auto [clean_polygons, face_map, point_map] =
    tf::cleaned(polygons, tolerance, tf::return_index_map);

// Reindex all associated mesh data
auto clean_face_normals = tf::reindexed(face_normals, face_map);
auto clean_vertex_attrs = tf::reindexed(vertex_attrs, point_map);
```

## Cleaning Soups

Polygon and segment soups (unindexed geometry) can also be cleaned. Since soups have no indices to deduce from, the index type defaults to `int`:

```cpp [soup_cleaning.cpp]
// Create a polygon soup from raw triangles
auto soup = tf::make_polygons(tf::make_blocked_range<3>(raw_points));

// Clean the soup - Index defaults to int
auto clean_mesh = tf::cleaned(soup);

// With tolerance
auto clean_mesh = tf::cleaned(soup, 1e-6f);

// Explicit index type
auto clean_mesh = tf::cleaned<int64_t>(soup);
```

::tip{icon="i-lucide-lightbulb"}
Cleaning a soup returns indexed geometry. This is how you convert raw triangle data into a proper indexed mesh with shared vertices.
::

## Index Maps

All cleaning operations can return index maps for tracking how elements were remapped:

```cpp [index_maps.cpp]
// Get index maps with tf::return_index_map tag
auto [clean_polygons, face_map, point_map] =
    tf::cleaned(polygons, tf::return_index_map);

// face_map.f() maps old face indices to new (or size() if removed)
// face_map.kept_ids() lists which original faces were kept

// point_map.f() maps old point indices to new (or size() if removed)
// point_map.kept_ids() lists which original points were kept

// Use maps to reindex associated data
auto clean_face_colors = tf::reindexed(face_colors, face_map);
auto clean_vertex_uvs = tf::reindexed(vertex_uvs, point_map);
```

## Low-Level Index Map Generation

For more control, use `tf::make_clean_index_map` directly:

```cpp [make_clean_index_map.cpp]
// Points - Index defaults to int
auto point_map = tf::make_clean_index_map(points);
auto point_map = tf::make_clean_index_map(points, tolerance);

// Segments - Index deduced from edges()[0][0]
auto [edge_map, point_map] = tf::make_clean_index_map(segments);
auto [edge_map, point_map] = tf::make_clean_index_map(segments, tolerance);

// Polygons - Index deduced from faces()[0][0]
auto [face_map, point_map] = tf::make_clean_index_map(polygons);
auto [face_map, point_map] = tf::make_clean_index_map(polygons, tolerance);

// Explicit index type
auto [face_map, point_map] = tf::make_clean_index_map<int64_t>(polygons);
```

::tip{icon="i-lucide-info"}
All cleaning operations automatically handle referential integrity, ensuring that after removing duplicate or unreferenced points, all edge/face indices are correctly updated.
::
