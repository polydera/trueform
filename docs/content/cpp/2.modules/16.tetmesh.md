The Tetmesh module fills the solid a closed surface encloses with tetrahedra. The surface is recovered exactly: every input face is a union of tetrahedron faces, and the tetrahedralization is constrained Delaunay.

Include the module with:

```cpp
#include <trueform/tetmesh.hpp>
```

## Meshing a Surface

```cpp [make_tet_mesh.cpp]
auto [tets, status] = tf::make_tet_mesh(mesh.polygons());

if (status == tf::tet_mesh_status::meshed) {
  for (auto tet : tets.tetrahedra()) {
    // tet[0..3] are the corner points, in double
  }
}
```

The mesh is emitted in double unless stated — `tf::make_tet_mesh<tf::none_t, float>` asks for float — because its points are lattice positions finer than a float holds (see [The Report](#the-report)). A form tagged with a frame is meshed where the frame places it, and its points come back in world space. A manifold edge link the form carries is read as it stands; a tree or face membership it carries is not read.

## Configuration

The call takes a `tf::tet_mesh_config`, shaped like the 2D CDT's `tf::cdt_config`. It is implicitly constructible from a `bool` alone, and a number converts to nothing:

```cpp [config.cpp]
// a tolerance in the input's coordinates: plane pooling, and every drain's band
auto [tets, status] = tf::make_tet_mesh(mesh.polygons(), {true, 1e-6});

// a tighter site budget, set by name
tf::tet_mesh_config budget;
budget.site_budget_ratio = 8;
auto [tets2, status2] = tf::make_tet_mesh(mesh.polygons(), budget);
```

| Field | Default | Meaning |
|-------|---------|---------|
| `split_constraints` | `true` | Cut the crossings the recovery finds; `false` meshes the surface as given |
| `tolerance` | `0.0` | Plane pooling, in the input's coordinates: faces one plane within it could hold pool onto that plane at the entrance, which builds no tree and no link for it; it is also the band every drain states its contacts in |
| `site_budget_ratio` | `32` | An integer: the sites a run may hold per site its entrance and its cut of crossings state; a recovery that would pass it refuses as `budget`, and the points the cut creates never count against it |

A crossing is found where the constraint recovery refuses it, and the triangles that cross along its curve are cut there, on the complex already built; `report.drains` counts the drains that cut and `report.triangles_cut` the triangles they traced, so a surface that crosses nowhere pays nothing for it. With `split_constraints` false the surface is meshed as given: no crossing is cut, `report.drains` is zero, and the first crossing the recovery names refuses, counted in `report.pairs_unresolved`. A clean surface gives the same cells either way.

```cpp [as_given.cpp]
auto [tets, status] = tf::make_tet_mesh(mesh.polygons(), {false});
```

The input converts once onto the exact integer lattice the library's converter gives its coordinate type, less the ten bits the constraint recovery splits below it, and every output point is a site's exact position mapped back. Where an edge needs a split finer than its frame, or a face a point its lattice does not name, that one site stands below the frame, as deep as the lattice admits — 23 bits for float input, 20 for double — and nothing else moves; `report.deep_sites` and `report.deepest` say how many and how deep. Faces that cross each other are cut where they cross, so a self-intersecting surface meshes too. Inside is decided by the surface's winding: a cell is kept when the surface winds around it a positive number of times, so a shell wound inward inside another is a cavity.

## The Boundary

Coplanar input triangles that meet, wound alike, form one facet — coplanar exactly, on the lattice. A facet is recovered as one region: its interior edges are not kept, and the tet mesh triangulates its interior freely. Ask for `tf::return_index_map` to receive a `tf::tet_mesh_index_map`: block `k` of `facet_triangles` holds the triangles of the tet mesh that cover facet `k`, indexed into `tets.points()` and wound as its faces; block `f` of `face_facets` lists, ascending, the facets input face `f` lies in — one, unless a crossing cut the face. The map is built only when asked:

```cpp [index_map.cpp]
auto [tets, status, map] =
    tf::make_tet_mesh(mesh.polygons(), tf::return_index_map);
for (auto facet : map.face_facets[f])
  for (const auto &triangle : map.facet_triangles[facet]) {
    // triangle[0..2] index tets.points()
  }
```

## The Report

The call answers a `tf::tet_mesh_status`. Ask for `tf::return_report` to receive the `tf::tet_mesh_report` in its place: the status, the counts that name a refusal's reason, the lattice that ran, and the diagnostics no status needs, which are measured only when asked. It composes with the index map:

```cpp [report.cpp]
auto [tets, report] = tf::make_tet_mesh(mesh.polygons(), tf::return_report);
auto [tets2, report2, map] = tf::make_tet_mesh(
    mesh.polygons(), tf::return_report, tf::return_index_map);
```

| Status | Meaning |
|--------|---------|
| `meshed` | Every face and edge recovered and the surface winds consistently |
| `refused` | Some constraint was refused, the entrance left a carrier without its triangles, or its lattice cannot resolve the crossings its passes kept naming. The report counts each kind: edges and faces needing a site deeper than the lattice admits, and edges whose recovery would pass the site budget, such as an edge passing a gap far narrower than itself. Where the lattice is the reason, state the deeper one with `tf::make_tet_mesh<std::int64_t>`. A mesh is returned only when the surface still winds consistently |
| `open` | The recovered surface has a hole: a rim of free edges that hangs off no non-manifold attachment (`tf::has_holes`); no mesh. `tf::fill_holes` closes a hole |
| `unwound` | The surface does not wind consistently, or it holds a sheet such as a flap whose free rim bounds nothing; no mesh |
| `rank_deficient` | The points do not span three dimensions |
| `capacity` | The cells or sites outgrew the index type |

`report.census` carries the constraint recovery's counts: segment rounds, corner-shell splits, refused segments, and the face routes — rebuilds, refinements, restorations.

Every tetrahedron is non-negative exactly; `report.flat` counts those whose corners are coplanar. The mesh is emitted in the output coordinate type, double by default; an export narrower than the lattice, float when asked for, may flatten a sliver below its resolution past zero, and `report.inverted` counts those cells. A closed surface wound inward encloses only cells of negative winding, so it meshes to no cell at all; `report.negative_cells` counts them, since the winding states the matter's side and is never repaired.
