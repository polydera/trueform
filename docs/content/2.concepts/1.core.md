`trueform` provides minimal, expressive primitives and their range counterparts, all enriched via composable policies. This section introduces the building blocks used throughout the library.

## Primitives

> primitive → primitive_range → form

Every primitive is a template of the form `primitive<Dims, Policy>`. Core primitives include points, vectors, lines, rays, planes, segments, polygons, and AABBs.

### Points and Vectors

```cpp [points_vectors.cpp]
// Vectors
tf::vector<float, 3> v0{1.f, 1.f, 1.f};
float buf[3]{2, 2, 2};
auto vview0 = tf::make_vector_view(buf);
auto uv1 = tf::make_unit_vector(v0);

// Points
tf::point<float, 3> pt0{{4, 4, 4}};
auto pview0 = tf::make_point_view(buf);
```

### Line and Ray

```cpp [line_ray.cpp]
auto line = tf::make_line_between_points(pt0, tf::random_point<float, 3>());
auto ray  = tf::make_ray_between_points(pt0, tf::random_point<float, 3>());
```

### Plane

```cpp [plane.cpp]
tf::unit_vector<float, 3> n = tf::make_unit_vector(v0);
auto plane0 = tf::make_plane(n, pt0);
auto plane1 = tf::make_plane(n, -tf::dot(n, pt0));
```

### Segment and Polygon

```cpp [segment_polygon.cpp]
auto seg = tf::make_segment_between_points(pt0, tf::random_point<float, 3>());
std::array<int, 3> face{0, 1, 2};
std::vector<float> raw_points = { 0,0,0, 1,0,0, 0,1,0 };
auto pts = tf::make_points<3>(raw_points);
auto tri = tf::make_polygon(face, pts);
```

### AABB

```cpp [aabb.cpp]
auto box = tf::aabb_from(tri);
auto c = box.center();
```

## Transformations and Frames

```cpp [transformations.cpp]
auto tr0 = tf::random_transformation<float>();
auto tr1 = tf::random_transformation<float>();
auto tr = tf::transformed(tr0, tr1);

// Frames hold a transformation and its inverse
tf::frame<float, 3> frame;
auto moved_pt = tf::transformed(pt0, frame);
```

## Queries on Primitives

```cpp [queries.cpp]
auto [d2, p0, p1] = tf::closest_metric_point_pair(tri, tri);
bool hit = tf::intersects(tri, seg);
auto ray = tf::make_ray_between_points(pt0, tf::random_point<float, 3>());
if (auto r = tf::ray_hit(ray, seg)) {
  auto [status, t, point] = *r;
}
```

## Primitive Ranges

Create semantic ranges with static-size propagation.

```cpp [ranges.cpp]
std::vector<int> ids;
auto triangles0 = tf::make_polygons(tf::make_blocked_range<3>(ids), pts);
auto segments0  = tf::make_segments(tf::make_slide_range<2>(ids), pts);
```

## Policies: tag and zip

Use `tag_*` to apply metadata to an object and `zip_*` to apply per-element data to a range.

```cpp [policies.cpp]
std::vector<std::string> ids_str;
std::vector<float> normals_flat;
std::vector<float> directions_flat;
std::vector<std::array<float, 3>> colors;

auto enriched = tf::make_points<3>(raw_points)
  | tf::tag_id("enriched points")
  | tf::zip_ids(ids_str)
  | tf::zip_normals(tf::make_unit_vectors<3>(normals_flat))
  | tf::zip_states(tf::make_unit_vectors<3>(directions_flat), colors);

auto transformed_point = tf::transformed(enriched.front(), frame);
```
