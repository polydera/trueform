The Topology module provides precomputed connectivity and higher-level structures for mesh reasoning.

## Connectivity Structures

### Face Membership

```cpp [face_membership.cpp]
tf::face_membership<int> fm;
fm.build(polygons);
for (auto face_id : fm[vertex_id]) {}
```

### Vertex Link (1-ring)

```cpp [vertex_link.cpp]
tf::vertex_link<int> v_link;
v_link.build(polygons.faces(), fm);
for (auto neighbor_vertex : v_link[vertex_id]) {}
```

### Face Link

```cpp [face_link.cpp]
tf::face_link<int> f_link;
f_link.build(polygons.faces(), fm);
for (auto nb_face : f_link[face_id]) {}
```

### Manifold Edge Link

```cpp [manifold_edge_link.cpp]
tf::manifold_edge_link<int, 3> me_link;
me_link.build(polygons.faces(), fm);
for (const tf::manifold_edge_peer<int>& peer : me_link[face_id]) {
  if (peer.is_boundary()) {}
  if (peer.is_manifold()) {}
}
```
