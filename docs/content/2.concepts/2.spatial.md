The Spatial module extends primitive-range queries with spatial structures and transforms via `tf::tree` and `tf::form`.

## Trees

```cpp [tree.cpp]
// Build a tree over any primitive range
auto pts = tf::make_points<3>(raw_points);
tf::tree<int, float, 3> tree(pts, tf::config_tree(4, 4));
```

## Forms

```cpp [form.cpp]
// Static form
auto form = tf::make_form(tree, pts);

// Dynamic form with a frame
auto frame = tf::random_transformation<float, 3>();
auto dynamic_form = tf::make_form(frame, tree, pts);
```

## Search

```cpp [search.cpp]
// Culling by AABB then applying a predicate to primitives
std::vector<int> inside_ids;
tf::search(
  form,
  [&](const auto &aabb){ return tf::distance2(aabb, tf::random_point<float,3>()) < 4.0f; },
  [&](const auto &p){ inside_ids.push_back(p.id()); }
);

// Pairwise search between two forms
std::vector<std::pair<int,int>> pairs;
tf::search(
  form, dynamic_form,
  tf::intersects_f,
  [&](const auto &a, const auto &b){ pairs.emplace_back(a.id(), b.id()); }
);
```

## Neighbor Search (kNN)

```cpp [knn.cpp]
auto query_pt = tf::random_point<float, 3>();
std::array<tf::nearest_neighbor<int, float, 3>, 10> buffer;
auto knn = tf::make_nearest_neighbors(buffer.begin(), 10/*, radius*/);

tf::neighbor_search(form, query_pt, knn);
```

## Ray Casting

```cpp [ray.cpp]
auto ray = tf::make_ray_between_points(tf::random_point<float, 3>(), tf::random_point<float, 3>());
if (auto result = tf::ray_hit(ray, form, tf::make_ray_config(0.f, 1e6f))) {
  auto [primitive_id, hit] = *result;
  auto [status, t, point] = hit;
}
```
