The Intersect module provides robust, exact intersection routines operating on primitives, ranges, and forms.

## Planar Arrangements

```cpp [planar_arrangements.cpp]
// Unordered 2D segments -> oriented faces and hole relations
tf::planar_arrangments<int, double> pa;
pa.build(segments);
for (auto [face, hole_ids] : tf::zip(pa.faces(), pa.holes_for_faces())) {
  auto polygon = tf::make_polygon(face, pa.points());
  for (auto hole : tf::make_indirect_range(hole_ids, pa.holes())) {
    auto hole_polygon = tf::make_polygon(hole, pa.points());
  }
}
```

## Scalar Field Slicing

```cpp [scalar_field.cpp]
// Slice polygons with a scalar field threshold
tf::scalar_field_intersections<int, float, 3> sfi;
sfi.build(polygons, scalar_field, /*cut_value*/ 0.0f);
auto edges = tf::make_intersection_edges(sfi);
auto segments = tf::make_segments(edges, sfi.intersection_points());
```

## Mesh-Mesh (Forms) Intersections

```cpp [forms_intersections.cpp]
// Compute intersections between two forms
tf::forms_intersections<int, double, 3> fi;
fi.build(form0, form1);
auto edges = tf::make_intersection_edges(fi);
auto segments = tf::make_segments(edges, fi.intersection_points());
```
