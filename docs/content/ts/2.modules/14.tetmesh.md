The Tetmesh module fills the solid a closed surface encloses with tetrahedra. The surface is recovered exactly: every input face is a union of tetrahedron faces, and the tetrahedralization is constrained Delaunay.

```ts
import * as tf from "@polydera/trueform";
```

## Tet Mesh

```ts
const result = tf.tetMesh(mesh);
// result.tetrahedra: NDArrayInt32 [T, 4]; result.points: NDArrayFloat64 [P, 3]
if (result.status === tf.TetMeshStatus.meshed) {
  // ...
}
tf.deleteTetMesh(result);

// off the main thread
const later = await tf.async.tetMesh(mesh, { tolerance: 1e-6 });
```

| Option | Type | Description |
|--------|------|-------------|
| `splitConstraints` | `boolean`, default `true` | Cut the crossings the recovery finds; without it the surface is meshed as given and a crossing in it refuses |
| `tolerance` | `number`, default `0` | Plane pooling, in the mesh's coordinates: near-coplanar faces pool onto one plane at the entrance, and it is the band of every drain |
| `siteBudgetRatio` | `number` | An integer: the sites a run may hold per site its entrance states. Default: the library's |
| `returnReport` | `boolean`, default `false` | Also return the report, measured only when asked |
| `returnIndexMap` | `true` | Also return the index map |

The points come back in float64 whatever the mesh's dtype: they are exact lattice positions mapped back, finer than a float32 holds. The mesh's transformation places it, so the points are world positions; its face membership and manifold edge link caches are reused. The result's arrays own WASM storage: release them with `tf.deleteTetMesh`, which leaves the input mesh untouched.

## The Index Map

```ts
const r = tf.tetMesh(mesh, { returnIndexMap: true });
// r.facetOffsets [K + 1] / r.facetTriangles [N, 3]: per facet, the boundary triangles covering it
// r.faceFacetOffsets [F + 1] / r.faceFacets: per input face, the facets it lies in, ascending
```

Coplanar input triangles that meet wound alike are one facet; a face lies in one facet unless a crossing cut it. The map is only computed when asked for.

## The Report

`result.status` is the call's answer, a `tf.TetMeshStatus` value:

| Status | Meaning |
|--------|---------|
| `meshed` | Every constraint recovered and the surface winds consistently; the mesh is the cells it winds positively |
| `refused` | Some constraint was refused, the entrance left a carrier without its triangles, or its lattice cannot resolve the crossings its passes kept naming; the report counts each kind. A mesh is returned only when the surface still winds consistently |
| `open` | The recovered surface has a hole, a rim of free edges that hangs off no non-manifold attachment; no mesh. `tf.fillHoles` closes a hole |
| `unwound` | The surface does not wind consistently, or it holds a sheet such as a flap whose free rim bounds nothing; no mesh |
| `rankDeficient` | The points span less than three dimensions |
| `capacity` | The cells or sites outgrew the index type |

The rest of the report is opt-in. Under `{ returnReport: true }`, `result.report` mirrors the C++ `tf::tet_mesh_report` in camelCase: `status` is a `tf.TetMeshStatus` value, refusals are counted by kind, and `census` carries the constraint recovery's counts. See the [C++ Tetmesh module](/cpp/modules/tetmesh) for every field.
